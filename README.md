# 駅のしおり

東京・神奈川・埼玉・千葉の訪れた駅を記録する、個人用の駅マップです。

## できること

- 1都3県の1,554駅名を収録（2026年11月2日取得データ）。
- 訪問済みの駅は青い丸と白いチェックで表示。
- 行きたい駅、訪問日、駅ごとのメモを記録。
- 駅名・よみ・メモ・路線・都県から検索、絞り込み。
- 地図をドラッグ、ピンチ、ボタンで拡大・移動。
- 記録をJSONで書き出し、読み込み。

同じ表記の駅名は会社・路線をまたいで1件にまとめます。溝の口と武蔵溝ノ口など、異なる表記は別々の記録です。離れた場所の同名駅も記録を共有しますが、地図の位置はそれぞれ残ります。

## 使い方

ビルド不要の静的サイトです。このフォルダーを静的Webホスティングに配置してください。GitHub Pagesで使う場合も、index.htmlと4つのJavaScriptファイルを同じフォルダーに置きます。

記録は閲覧端末のブラウザ内（localStorage）に保存されます。アカウントやクラウド同期はありません。定期的に「書き出し」でバックアップしてください。別のURL・端末・ブラウザへ移る場合は、旧画面で書き出して新しい画面で読み込みます。

このリポジトリに個人の訪問履歴やメモは含まれていません。

## データと出典

- 駅・路線: [TERAREN 駅・路線情報API](https://train.teraren.com/)（[駅データ.jp](https://www.ekidata.jp/)無料版を使用）。営業中フラグ、都県、駅名の完全一致に基づいて加工。
- 背景の線路形状: 国土交通省 [国土数値情報 鉄道データ（N02・2024年）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html)を加工。JSON変換には[antfu/mlit-json](https://github.com/antfu/mlit-json)を使用。

駅と背景のデータ時点は異なります。新線・移設・営業状況・列車の停車駅や乗換案内は、各鉄道会社の公式情報を確認してください。
